# KAHRELUM OS

**Hasan Raza Kazmi** — Founder, KAHRELUM OS

KAHRELUM OS is the operating system for evidence-grounded AI and research work that must be traceable, decision-useful, and reviewed by a human before action.

Canonical architecture and doctrine: **[kahrelum-os](https://github.com/AuroraGrid/kahrelum-os)**

Public systems under KAHRELUM OS focus on AI evaluation, agent workflows, source verification, research operations, technical implementation, and controlled publication. Each system separates documented facts from inference, forecasts, and unverified claims.

## Operating standard

Separate facts from inference. State what remains unproven. Document constraints and falsifiers. Do not confuse model confidence with accuracy.
